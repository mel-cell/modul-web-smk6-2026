# Halaman Kalender Akademik

Halaman kalender menampilkan jadwal akademik, event penting, dan kegiatan sekolah dalam format kalender interaktif.

## Tampilan Halaman

![Tampilan Halaman Kalender](/modul-web-smk6-2026/img/tampilan-web/kalender.png)

## Fitur-Fitur Utama

### 1. Kalender Month View
- Tampilan kalender bulan
- Navigasi ke bulan sebelumnya/berikutnya
- Highlight hari-hari penting
- Quick view untuk event

### 2. Event Types
- Hari Libur (warna merah)
- Hari Efektif (warna biru)
- UTS/UAS (warna oranye)
- Event Khusus (warna hijau)
- Pengumuman (warna ungu)

### 3. Event Details
- Judul event
- Tanggal dan waktu
- Deskripsi lengkap
- Lokasi/tempat
- Pic atau kontak

### 4. Filter dan Search
- Filter by kategori event
- Filter by bulan/tahun
- Search by nama event
- View selector (Month, Week, Day)

### 5. Event List
- Daftar event dalam format list
- Sorting by tanggal
- Timeline view
- Upcoming events highlight

### 6. Download Calendar
- Export ke iCal format
- Sync dengan Google Calendar
- PDF download

### 7. Notifikasi
- Subscribe ke event tertentu
- Reminder notification
- Email alert

## Content Contoh

- **Hari Libur Nasional**: 1 Jan, 14 Feb, 1 Mei, dll
- **Semester**: Awal Semester, Akhir Semester
- **Ujian**: UTS, UAS, Ujian Sekolah
- **Event Khusus**: PPDB, Wisuda, Pertemuan Orang Tua, Pramuka

## Layout

- **Desktop**: Full calendar view + event list sidebar
- **Mobile**: Compact calendar + full event details di bawah
