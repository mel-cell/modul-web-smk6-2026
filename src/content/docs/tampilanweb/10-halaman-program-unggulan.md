# Halaman Program Unggulan

Halaman program unggulan menampilkan program-program spesial dan unggulan yang menjadi keunikan sekolah.

## Tampilan Halaman

![Tampilan Halaman Program Unggulan](/modul-web-smk6-2026/img/tampilan-web/programunggulan.png)

## Fitur-Fitur Utama

### 1. Hero Section Program
- Banner atau highlight untuk program unggulan
- Tagline atau motto program
- Call-to-action

### 2. Daftar Program
- Card untuk setiap program unggulan
- Icon atau gambar representatif
- Nama program
- Deskripsi singkat
- Link ke detail program

### 3. Detail Program
- Tujuan program
- Target pembelajaran
- Keunggulan kompetitif
- Kurikulum atau modul pembelajaran
- Pencapaian atau testimoni

### 4. Fitur Unggulan
- Keunikan program
- Metode pembelajaran
- Sertifikasi atau output
- Peluang karir

### 5. Testimoni dan Hasil
- Testimoni dari alumni
- Data kelulusan dan penempatan
- Success stories

### 6. Pendaftaran Program
- Informasi persyaratan
- Jadwal pendaftaran
- Kontak atau form pendaftaran

## Program Contoh

Program unggulan yang mungkin ditampilkan:
- **Program Akselerator**: Untuk siswa berprestasi
- **Program Bilingual**: Pembelajaran dengan bahasa inggris
- **Program Industri Partnership**: Magang bersama industri
- **Program Research & Innovation**: Penelitian dan inovasi
- **Program Character Building**: Pengembangan karakter dan kepemimpinan
