# Halaman Detail Berita

Halaman detail berita menampilkan konten lengkap dari sebuah artikel berita dengan fitur navigasi dan rekomendasi.

## Tampilan Halaman

![Tampilan Halaman Detail Berita](/modul-web-smk6-2026/img/tampilan-web/detailberita.png)

## Fitur-Fitur Utama

### 1. Header Berita
- Judul berita yang menonjol
- Thumbnail gambar utama
- Tanggal publikasi, penulis, dan kategori

### 2. Konten Utama
- Isi berita dengan formatting text yang proper
- Embedded images dalam artikel
- Links ke referensi atau halaman lain

### 3. Metadata Berita
- Waktu baca (reading time)
- Jumlah views
- Tags atau label berita

### 4. Share Buttons
- Tombol share ke media sosial
- Copy link button
- Print button

### 5. Navigasi Berita
- Link ke berita sebelumnya
- Link ke berita berikutnya
- Breadcrumb navigation

### 6. Berita Terkait
- Daftar 3-5 berita dengan topik serupa
- Thumbnail dan ringkasan singkat
- Link ke detail berita

### 7. Sidebar Opsional
- Daftar kategori berita
- Berita populer
- Newsletter subscription form

## Breadcrumb Navigation

Menunjukkan path pengguna:
- Home > Berita > Judul Berita
