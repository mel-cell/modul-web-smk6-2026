# Halaman Smart Tour (Virtual Tour 360°)

Halaman smart tour menyediakan pengalaman virtual tour interaktif 360 derajat untuk menjelajahi fasilitas sekolah secara online.

## Tampilan Halaman

![Tampilan Halaman Smart Tour](/modul-web-smk6-2026/img/tampilan-web/smarttour.png)

## Fitur-Fitur Utama

### 1. Viewer 360°
- Display panorama 360 derajat
- Mouse drag untuk rotasi view
- Zoom in/out control
- Fullscreen mode

### 2. Navigation Points
- Hot spots untuk point of interest
- Info box saat hover
- Click untuk pindah ke lokasi lain
- Navigation breadcrumb

### 3. Location List
- Daftar semua lokasi yang bisa ditour
- Thumbnail preview
- Kategori lokasi
- Search dan filter

### 4. Information Panel
- Nama lokasi
- Deskripsi detail
- Fitur dan fasilitas di lokasi
- Foto tambahan

### 5. Interactive Elements
- Marker dengan icon untuk point of interest
- Audio narasi (opsional)
- Timeline atau sequence tour
- Mode guided vs free exploration

### 6. Lokasi Virtual Tour
Contoh lokasi yang disediakan:
- Lobby/Entrance
- Ruang Kepala Sekolah
- Ruang Guru
- Ruang Kelas
- Laboratorium
- Perpustakaan
- Aula
- Kantin
- Lapangan Olahraga
- Area Parkir

### 7. Device Support
- Desktop dengan mouse
- Tablet dengan touch
- Mobile dengan gyroscope (VR cardboard compatible)
- Keyboard controls

## User Experience

- Seamless transition antar lokasi
- Informative tooltips
- Loading indicator
- Mobile-friendly interface

## Browser Compatibility

Works on:
- Chrome/Chromium
- Firefox
- Safari
- Edge
