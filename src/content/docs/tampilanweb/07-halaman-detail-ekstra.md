# Halaman Detail Ekstrakulikuler

Halaman detail ekstrakulikuler menampilkan informasi lengkap tentang sebuah organisasi atau kegiatan ekstrakurikuler.

## Tampilan Halaman

![Tampilan Halaman Detail Ekstrakulikuler](/modul-web-smk6-2026/img/tampilan-web/detailekstra.png)

## Fitur-Fitur Utama

### 1. Header Detail Ekstra
- Logo/banner ekstrakulikuler
- Nama dan kategori
- Status (Aktif/Tidak Aktif)

### 2. Informasi Dasar
- Pembina/Pelatih dengan foto
- Waktu pertemuan
- Tempat pertemuan
- Target/tujuan kegiatan

### 3. Deskripsi Lengkap
- Latar belakang kegiatan
- Program dan kegiatan yang dilakukan
- Prestasi atau achievement
- Testimoni anggota

### 4. Galeri Kegiatan
- Foto-foto kegiatan ekstrakulikuler
- Video kegiatan (opsional)
- Dokumentasi event atau kompetisi

### 5. Anggota dan Struktur
- Daftar pengurus
- Foto dan nama anggota
- Struktur organisasi

### 6. Pendaftaran
- Informasi persyaratan
- Waktu pendaftaran
- Contact person untuk daftar
- Form pendaftaran (jika ada)

### 7. Navigasi
- Link ke ekstra lainnya
- Breadcrumb navigation
- Back button

## Layout

Menggunakan layout yang rapi dengan sidebar untuk informasi ringkas dan konten utama di tengah.
