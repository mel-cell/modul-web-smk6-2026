# Halaman Home

Halaman home adalah pintu masuk utama website SMK Negeri 6 Malang. Halaman ini menampilkan informasi ringkas tentang sekolah, berita terbaru, dan akses cepat ke berbagai fitur penting.

## Tampilan Halaman

![Tampilan Halaman Home](/modul-web-smk6-2026/img/tampilan-web/home.png)

## Fitur-Fitur Utama

### 1. Header/Navigation Bar
- Logo sekolah dan nama SMK Negeri 6 Malang
- Menu navigasi utama (Beranda, Profil, Akademik, Ekstra, Galeri, etc.)
- Responsive design untuk mobile dan desktop

### 2. Hero Section
- Banner promosi sekolah dengan latar belakang menarik
- Call-to-action button untuk informasi lebih lanjut

### 3. Berita Terbaru
- Menampilkan 3-5 berita terkini
- Thumbnail gambar, judul, dan tanggal publikasi
- Link ke halaman detail berita

### 4. Pilihan Jurusan
- Card dengan daftar jurusan yang tersedia
- Icon representatif untuk setiap jurusan
- Link ke halaman detail jurusan

### 5. Program Unggulan
- Showcase program-program unggulan sekolah
- Deskripsi singkat dan link untuk detail

### 6. Footer
- Informasi kontak sekolah
- Link media sosial
- Copyright information

## Responsivitas

Halaman ini dioptimalkan untuk:
- 📱 Mobile (320px - 480px)
- 📱 Tablet (481px - 768px)
- 💻 Desktop (769px keatas)
